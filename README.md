=======
This project is a mobile and web application designed to manage the robe rental process for UNIMAS. 
 
## Key Features 
- **Graduand App:** Allows students to book robes and make payments. 
- **Admin Dashboard:** Enables staff to track inventory and bookings. 
- **Backend:** Node.js server handling API requests. 
 
## Setup Instructions 
1. Clone the repository. 
2. Run 'npm install' to install dependencies.
